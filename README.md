# La cucina — личная книга рецептов

Полноэкранная итальянская обложка, морская палитра и 12 любимых рецептов.
Сайт работает на GitHub Pages без сборки и внешних runtime-зависимостей.

## Локальный просмотр

Нужны Python 3 и, для тестов, Node.js 20 или новее.

```sh
npm run dev
```

Откройте http://127.0.0.1:4187. Если порт занят:

```sh
python3 -m http.server 4188 --bind 127.0.0.1
```

Открывать index.html через file:// не следует: браузер блокирует загрузку модулей
и JSON с локального диска. Устанавливать npm-пакеты не требуется.

## Что изменено

- Обложка ужина на озере Комо, созданная специально для проекта; отдельная вертикальная композиция для телефона и планшета.
- Палитра Macrame Cream, Cenote Blue, Dried Palm и Driftwood из пользовательского референса.
- Каллиграфия MonteCarlo, книжные заголовки Cormorant Garamond и Montserrat для текста. Все шрифты загружаются локально.
- Поиск по названию и ингредиентам, фильтры по категориям, избранное с сохранением на устройстве.
- Страницы рецептов с отмечаемыми ингредиентами, исходными вариантами, фотографиями шагов, заметками и КБЖУ, где они были указаны в оригинале.
- Плавные появления, анимации наведения, закреплённая навигация; поддержка prefers-reduced-motion и клавиатуры.

## Структура

- index.html — документ и метаданные.
- styles.css — типографика, цвета, адаптивность и анимации.
- src/app.js — интерфейс и навигация.
- src/recipes.js — поиск, категории и вспомогательные функции.
- data/recipes.json — все оригинальные данные 12 рецептов и 13 вариантов.
- data/step-photos.json — 61 фотография шагов и две обложки.
- recipes/ и assets/ — локальные фотографии и шрифты.
- docs/design.md — направление, референсы и происхождение изображений.
- docs/verification.md — выполненные проверки.

Исходные скомпилированные book-_.js и book-_.css оставлены для аудита
сохранности контента; новый интерфейс их не загружает. Тест сравнивает все
поля JSON с оригинальной книгой. Ссылки #/recipes/:slug?v=... сохранены.

## Проверка

```sh
npm run check
```

Проверяет синтаксис JavaScript, неизменность оригинальных данных,
наличие всех фотографий, поиск, фильтры, ссылки вариантов и счётчик.

## Публикация

Содержимое репозитория готово для GitHub Pages из корня ветки main.
Сборка не нужна, .nojekyll сохранён. После слияния изменений в main GitHub Pages
публикует обновление по существующему адресу сайта.

## Шрифты и изображения

На предоставленном образце слово Camellia набрано Andasia от Din Studio.
Файл и веб-лицензия Andasia не предоставлены. Поэтому в проект включён
визуально близкий открытый MonteCarlo; это не точный Andasia. Заменить
семейство можно через токен --script после предоставления лицензированного
веб-шрифта. Cormorant Garamond и MonteCarlo распространяются по OFL;
лицензии находятся в assets/fonts/.

Две обложки сгенерированы встроенным image_gen для этого проекта.
Оригинальные фотографии и тексты рецептов сохранены вместе с источниками.
Избранное хранится только в браузере пользователя и не синхронизируется
между устройствами. Отметки ингредиентов живут до перезагрузки страницы.
