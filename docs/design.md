# La cucina · озеро Комо

Задача: обновить личную книгу рецептов, сохранив все 12 блюд, варианты,
ингредиенты, источники, заметки, пищевую ценность и пошаговые фотографии.
Направление взято из конкретного брифа пользователя: итальянская вилла,
ужин вдвоём, полноэкранная фотография, каллиграфия и морская палитра.

| Решение                     | Основание                               | Роль                                                   |
| --------------------------- | --------------------------------------- | ------------------------------------------------------ |
| Полноэкранный ужин на Комо  | Сцена из запроса                        | Сгенерированная обложка 16:9, люди справа, текст слева |
| Cenote Blue #174A6E         | Присланная палитра                      | Кнопки, навигация, заголовки и футер                   |
| Macrame Cream #EBE4D3       | Присланная палитра                      | Основной холст, светлый текст на фото                  |
| Dried Palm #C7AD7E          | Присланная палитра                      | Акценты и декоративные детали                          |
| Driftwood #999388           | Присланная палитра                      | Разделители; текст использует более тёмный оттенок     |
| MonteCarlo                  | Каллиграфический характер образца       | Итальянское название и обложка, открытая OFL-лицензия  |
| Cormorant Garamond          | Книжное настроение + руководство Refero | Кириллические заголовки и короткие цитаты              |
| Montserrat                  | Сохранён из текущего сайта              | Текст рецептов и элементы управления                   |
| Появления, сдвиг до 14px    | Руководство Refero по движению          | transform/opacity; учёт reduced-motion                 |
| Поиск, категории, избранное | Задача книги — выбрать рецепт           | Пустые состояния, счётчик, сохранение на устройстве    |

Refero MCP был вызван для трёх направлений, но вернул NO_SUBSCRIPTION.
Резерв: пользовательские референсы и bundled refero-design/references/
typography.md, motion.md, visual-workflow.md. Пользователь поручил
самостоятельно довести редизайн до результата.

На образце слово Camellia набрано шрифтом Andasia (Din Studio).
Файл Andasia и веб-лицензия не предоставлены; используется открытый
визуально близкий MonteCarlo. Источник: https://www.dafont.com/andasia.font
Шрифты и лицензии: https://github.com/google/fonts/tree/main/ofl/montecarlo
и https://github.com/google/fonts/tree/main/ofl/cormorantgaramond

Исходный репозиторий содержит только скомпилированные React JS/CSS.
Данные вынесены без изменения в JSON; новый интерфейс — HTML/CSS/JS
без сборки и runtime-зависимостей, совместимый с GitHub Pages.
Старые хеш-ссылки #/recipes/:slug?v=... сохранены.

Обложка создана встроенным image_gen. Промпт: photorealistic editorial
landscape photograph; man and woman sharing pasta and margherita pizza
on an Italian villa terrace overlooking Lake Como; couple on the right,
shaded loggia and olive tree on the left for text; cream linen, blue lake,
sandy stone, warm late afternoon light; no text/logos.

Вертикальная обложка: edit built-in image_gen по исходной фотографии;
портрет 9:16, та же пара, оба человека в верхней половине,
озеро на заднем плане и спокойная затенённая нижняя половина для текста.
Файлы: assets/como-dinner.jpg и assets/como-dinner-mobile.jpg.
Оба изображения оптимизированы в JPEG; мобильный файл выбирается через picture.
